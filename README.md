## 🌟 Featured Project

### 💳 Flo Wallet — Digital Wallet Application
A comprehensive, modern fintech digital wallet application designed for seamless financial transactions, built with absolute structural precision.

- **Architecture:** Formulated entirely upon **Clean Architecture**, enforcing strict boundaries between the Presentation layer (UI & BLoC), Domain layer (Use Cases & Entities), and Data layer (Repositories & Data Sources).
- **Backend Infrastructure:** Powered by **Firebase** for secure user authentication and scalable cloud database solutions.
- **Media Management:** Integrated with **Cloudinary** for optimized and secure asset/file uploads.
- **Advanced Features:**
  - 🔍 **Smart QR Code Scanner:** For instant, frictionless peer-to-peer transactions.
  - 📊 **Real-time Transactions:** Dynamic live transaction history syncing.
  - ⚠️ **Advanced Exception Handling:** A centralized, robust error-handling mechanism that gracefully intercepts failures across all layers to guarantee a smooth and uninterrupted user experience.
